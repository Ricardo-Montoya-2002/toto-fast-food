# TOTO Fast Food

Web de TOTO Fast Food: carta digital con pedidos por WhatsApp.

## Cómo cambiar precios
- Edita `carta.js`: cambia solo el número de `precio`.
- O abre la web con `#precios` al final del enlace, cambia los precios, toca **Copiar carta** y pega el texto en `carta.js`.

Al guardar cambios aquí, GitHub Pages actualiza la web en 1 o 2 minutos.
